# Продолжение CompanionLab в облаке

Репозиторий: https://github.com/bagrat261/companionlab. Это настоящий GitHub fork `lachydotmcg/capri-desktop`; лицензия оригинала и уведомления об авторстве сохранены. Основная рабочая ветка для продолжения: `main`. Резервная версия до обновления: `companionlab/iteration-1-v0.8.2`.

## Выбор в Codex Cloud

1. В новой задаче Codex выберите **Work in → Cloud → Select environment → Create environment**.
2. Выберите `bagrat261/companionlab`. Если репозитория нет в списке, предоставьте GitHub-интеграции Codex доступ к этому репозиторию.
3. Создайте и опубликуйте окружение (**Publish**), затем выберите ветку `main` для задачи.
4. Попросите агента сначала прочитать `AGENTS.md`, `COMPANIONLAB.md`, этот файл и `docs/UPDATE-0.8.3.md`.

Облачное окружение автоматически не создавалось. Выгрузка Git-репозитория и настройка окружения Codex являются разными действиями. Официальная инструкция: https://learn.chatgpt.com/docs/environments/cloud-environments.

В облако отправлены исходники и история Git. Локальные веса GGUF, ключи, история бесед, пользовательские настройки, установленные программы и `out/` не отправляются. Облачный localhost не подключается к модели на домашнем Windows-компьютере. Для работы с реальной LLM настройте доступный провайдер отдельно.

## Платформы

Работать с облачным репозиторием с Mac можно независимо от ОС целевого приложения. Windows CompanionLab использует WinForms/.NET Framework 4.8; его GUI нельзя проверить в обычном Linux-контейнере Codex Cloud.

В оригинале уже существует отдельный интерфейс `cross/` на Avalonia и .NET 10 для macOS/Linux. Релиз 0.8.3 заметно расширяет его Mainframe. Это основа будущего Mac-приложения, но наша система профилей пока подключена только к Windows. В `cross/` ещё остаются исходная идентичность Capri, собственные настройки и отличия в разрешениях. Не выдавайте эту сборку за готовый изолированный CompanionLab для Mac и не запускайте её поверх существующей установки Capri.

Для проверки компиляции `cross/` в облаке нужен .NET SDK 10:

```sh
dotnet build cross/Capri.Cross.csproj -c Release
```

Windows-сборка проверяется на Windows; существующий `.github/workflows/ci.yml` содержит Windows, Linux и macOS jobs. Запуск Actions в новом форке может потребовать включения workflows владельцем. Успех всех jobs не заявляется: исходная полная smoke-suite уже имела ошибки до наших изменений.

## Следующий рабочий этап

Сначала подтвердить облачную сборку и результаты CI. Для Mac выделить проверку manifest/personality из `Characters.cs` в переносимую часть, оставить декодирование и snapshot PNG в адаптере рендерера, подключить выбор профилей к Avalonia Pet/Mainframe. Перед запуском изменить идентификаторы, каталоги, startup/update paths и безопасные значения по умолчанию cross-сборки. Не переписывать AI Core: общий `Brain.cs` уже используется обеими версиями.

Перенос не завершён: реальные проверки macOS, голоса, разрешений Accessibility/Screen Recording/Microphone и нескольких экранов требуют Mac. Windows-данные не следует автоматически переносить: ключи могут быть защищены Windows DPAPI.
