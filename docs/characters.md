# Character System v1

Профиль является локальными данными. Он не содержит скриптов, DLL, команд запуска, ключей провайдеров или модов. Загрузчик не устанавливает зависимости.

## Каталоги

```text
%LOCALAPPDATA%/CompanionLab/
  settings.json
  chat.json
  me.md
  memories.md
  characters/
    selected.txt
    luna/
      character.json
      personality.md
      assets/idle.png
  character-settings/
    luna/personality.md
```

`characters/*/personality.md` — исходная личность пакета. `character-settings/*/personality.md` — отдельная пользовательская правка, создаваемая кнопкой редактирования личности. Reset удаляет только пользовательскую правку, возвращая исходную личность профиля. Настройки Capri используют прежний `CompanionLab/personality.md`. Пакет персонажа при сбросе не изменяется.

Встроенный `characters/capri/character.json` компилируется в EXE. Его id `capri` зарезервирован, графика и исходная личность берутся из кода и embedded resources Capri. Копировать эту папку в пользовательский каталог не нужно.

## Формат

```json
{
  "schemaVersion": 1,
  "id": "luna",
  "name": "Luna",
  "renderer": "capri-strip-v1",
  "personalityFile": "personality.md",
  "voice": { "mode": "local", "style": "Bright", "pitch": 2, "speed": 110 },
  "sprites": [ { "slot": "idle", "file": "assets/idle.png" } ]
}
```

| Поле | Ограничение |
|---|---|
| schemaVersion | Только `1` |
| id | 1–48 символов: первая строчная латинская буква, затем `a-z`, `0-9`, `_`, `-`; уникален в каталоге |
| name | 1–48 видимых символов, включая русский; без управляющих и форматирующих символов |
| renderer | Только `capri-strip-v1`; неизвестный и 3D-рендерер отклоняются |
| personalityFile | Необязательно; относительный UTF-8 файл, не более 36 KiB / 9000 символов; отсутствующий указанный файл является ошибкой |
| voice.mode | `inherit`, `local`, `off`; по умолчанию `inherit` |
| voice.style | Для `local`: `Her own`, `Bright`, `Sly`, `Sharp` |
| voice.pitch | От -12 до 12 |
| voice.speed | 50–200 процентов; отсутствующий/нулевой параметр означает 100 |
| sprites | Не более 64 уникальных слотов; PNG до 50 MiB каждый и до 64 MiB на профиль |

Манифест ограничен 64 KiB. Профили находятся непосредственно в подпапках `characters`. Абсолютные пути, `..`, alternate data streams, symlink и junction внутри профиля отклоняются. Повреждённый профиль пропускается с диагностикой; отсутствие сохранённого персонажа возвращает встроенную Capri.

## Спрайты и поведение

Это первый адаптер к существующему рендереру, а не универсальный редактор анимаций. `slot` совпадает с именем PNG в `assets/sprites` без расширения: например `idle`, `blink`, `mouth`, `perch`, `perch_talk`, `perch_music`, `laydown`, а также имеющиеся `_flipped` варианты. Полный перечень определяется ресурсами исходной Capri.

Каждый override должен иметь те же размеры полосы, количество кадров и раскладку, что и соответствующий оригинальный PNG. Отдельные Fps/геометрия/скелет в v1 не задаются. Пропущенные слоты наследуют исходную графику. Без собственных override второй профиль продолжает выглядеть как Capri.

Заголовок и размеры PNG проверяются до декодирования. Проверенные сжатые байты сохраняются в объекте профиля; рендерер не переоткрывает изменяемые файлы на каждом кадре или ленивой загрузке. При выборе профиля кеш декодированных полос сбрасывается, незавершённая фоновая загрузка старого поколения не попадает в новое. Новый выбор того же профиля заново читает его пакет.

Все действия и анимации v1 относятся к фиксированному набору Capri. Существующая схема инструментов ограничивает названия действий; произвольные строки от LLM не создают новую анимацию. Настраиваемые соответствия эмоций и индивидуальная геометрия относятся к следующей версии адаптера.

## Личность, AI и голос

`CharacterCatalog` не зависит от Brain, провайдера LLM или устройства голоса. `CharacterHost` связывает профиль с существующими компонентами приложения. `Brain.UseCharacter` меняет личность, но сохраняет базовые правила Safety/Machinery после неё и исходный фильтр личности. Профиль не меняет список инструментов и разрешения. Выбор не заменяет Brain и не очищает его историю.

Если personalityFile отсутствует, используется нейтральная личность с именем профиля. Пользовательская правка хранится отдельно; при перезапуске/выборе пакет загружается и проверяется снова.

`inherit` использует настроенный голос Capri при первом выборе профиля. `local` переключает существующий Kokoro-маршрут и его стиль, pitch/speed. `off` отключает речь. Загрузка весов не выполняется самим выбором персонажа; без настроенного локального голоса фактический звук не обещается.

После пользовательской настройки голосовые параметры сохраняются по id персонажа. Текущий владелец плоских voice-настроек записывается отдельно, чтобы восстановление при исчезновении профиля не перезаписало голос Capri. Cloud-ключи и конфигурация внешнего voice server остаются общими настройками приложения; собственные произвольные TTS-движки и endpoint на профиль в v1 не реализованы.

Выбор доступен через **Characters** в контекстном меню персонажа и трея. Переключение отклоняется во время активного диалога, синтеза/воспроизведения, задачи, перетаскивания или активного клонирования. Индикация использует имя профиля в меню, tooltip трея и accessibility name. Часть унаследованного интерфейса и готовых реплик всё ещё содержит имя Capri.

## Расширение

Новый renderer сможет получать CharacterProfile и реагировать на состояние агента через отдельный адаптер. AI-провайдеры, память и разрешения менять для этого не требуется. VRM/3D и свободные размеры спрайтов пока не поддерживаются, и манифест с таким renderer отклоняется явно.
